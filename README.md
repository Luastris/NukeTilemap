# NukeTilemap

The grid-world module for [NukeEngine](https://github.com/Luastris/NukeEngine-Eco) —
colony sims, roguelikes, strategy. A separate module by design: most projects never need
a tilemap, so it ships only with the games that do. Native game modules link
`NukeTilemap.lib` for direct C++ access (the hot path — mapgen fills, A* reads); scripts
reach the same component through reflection (Lua `atom:getComponent("Tilemap")`, C#
`GetComponent<Tilemap>()`).

## Model

- ONE `Tilemap` component owns the whole map as FLAT arrays — a cell is an index, never
  an object.
- N named LAYERS (terrain / floor / things / zones...), each cell: uint16 tile id
  (0 = empty), uint8 visual variant, uint8 free user byte (plant growth, wall HP
  bucket, ...).
- Tile DEFS live in `.nutile` JSON assets (texture atlas + per-tile cells / walkability /
  flags; multiple tile sets combine through a global id space) — a cell stores only the
  id, costs are functions of the def stack. The `.nutile` editor ships in the companion
  [NukeTilemapEditor](https://github.com/Luastris/NukeTilemapEditor) module.
- The map lies in the atom's LOCAL XY plane (like Canvas): rotate the atom flat for a
  top-down ground or keep it vertical for a 2D side view. `cellSize` world units per
  cell.
- RENDERING: 32×32-cell chunks baked into sprite-batch vertex runs (one draw per layer
  per atlas), frustum-culled per chunk, dirty-rebaked on `SetTile`; lit tiles with
  normal-mapped atlases supported. Zero new PSOs.
- SERIALIZATION: layers pack RLE+CBOR+base64 into a hidden prop on save and decode on
  load — savegames carry the live map.
- Pathfinding: the engine's async grid A* reads walk costs straight from the def stack.

## Building

Part of the [NukeEngine-Eco](https://github.com/Luastris/NukeEngine-Eco) superbuild, or
standalone: `cmake -S . -B build -G "Visual Studio 17 2022" -A x64` +
`cmake --build build --config Debug` (needs `VCPKG_ROOT`; engine first). The build copies
`NukeTilemap.dll` into the runtime `modules/` folder; reflection code is generated by the
nukegen prebuild from `include/NukeTilemap/Tilemap.h`.
